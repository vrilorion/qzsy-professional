WINDOWS APPLICATION

七政四余 professional

Version 1.0.0

中国伝統占星術「七政四余」の占星盤を作成する Windows用アプリケーション。

VRIL ORION が提供する無料ソフトウェアです。

主な機能

七政四余の天体計算

七政四余11天体の位置を計算し、秒単位まで表示します。

占星盤の作成

実用性を重視した3種類の占星盤を表示します。

鑑定に必用な要素

変曜、輝度、主難仇恩用、十二運、神殺などを表示します。

運期の算出

大限、童限、小限、月限に対応し、鑑定時の天体の位置も表示します。

占星盤の画像保存

作成した占星盤をPNG画像として保存できます。

AI用データの保存

占星盤の情報をJSON形式のデータとしてZIP保存できます。

インストール方法

  1. 「無料ダウンロード」ボタンをクリックします。
  2. ダウンロードが終わったら、画面右上の「↓」マークをクリックします。
  3. 表示された「QZSYProfessional_Setup_v1.0.0.exe」をクリックして起動します。
  4. 案内に従ってインストールします。デスクトップに「七政四余 professional」のアイコン（ショートカット）が作成されます。
  5. デスクトップの「七政四余 professional」アイコンをダブルクリックして、アプリを起動します。

ダウンロードした「QZSYProfessional_Setup_v1.0.0.exe」は、エクスプローラーの「ダウンロード」フォルダーに保存されています。それをダブルクリックしてもインストールを開始することができます。

Windowsのセキュリティ機能によりインストーラーの起動時に「WindowsによってPCが保護されました」という警告が表示される場合がありますが、本ソフトウェアはWindows 11で動作確認済みです。「詳細情報」をクリック→「実行」をクリックしてインストールを進めてください。
